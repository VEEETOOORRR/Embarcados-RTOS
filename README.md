Este repositório tem como objetivo armazenar os projetos STM32Cube referentes ao módulo RTOS da capacitação Sistemas Embarcados para PSII (2026.2) oferecida pela VIRTUS-CC.

Os projetos são desenvolvidos fazendo uso do microcontrolador STM32F407VET6.

0 - Projeto template CubeMX pré-configurado para utilizar o FREERTOS CMSIS_V2
1 - Projetos e relatórios referentes à atividade "Prioridades de Tarefas no FreeRTOS"
2 - Projetos e relatórios referentes à atividade "Prioridades, Semáforos e Mutex"
